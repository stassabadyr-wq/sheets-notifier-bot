# 🔔 Sheets Notifier Bot

Telegram-бот, который следит за XLSX-файлом на Яндекс Диске и присылает уведомления при появлении новых строк.

## Возможности

- 📋 **Добавление файлов** — по публичной ссылке на папку Яндекс Диска + имя файла
- 🔔 **Уведомления** — при появлении новой строки в XLSX
- ⏸ **Пауза / включение** — временно отключить отслеживание
- 👁 **Проверка вручную** — «Проверить сейчас» без ожидания
- 🗑 **Удаление** — с подтверждением
- 🛡 **Защита от дублей** — одна строка отправляется один раз
- 🛠 **Админ-панель** — статистика и список всех отслеживаний
- 🇷🇺 **Полностью работает в России** — без Google, без VPN

## Технологии

- **Python 3.11+**
- **aiogram 3.x** — Telegram-бот
- **Yandex Disk API** — получение прямых ссылок на файлы
- **pandas** — чтение XLSX (надёжнее, чем openpyxl для файлов из Яндекс Документов)
- **SQLite + aiosqlite** — хранение настроек
- **AsyncIO** — worker + бот одновременно

## Как это работает

1. Пользователь создаёт **папку** на Яндекс Диске
2. Кладёт в неё **XLSX-файл** (например, `Заявки.xlsx`)
3. Делает папку **публичной** (доступ по ссылке)
4. Отправляет боту **ссылку на папку** и **имя файла**
5. Бот сохраняет настройки в SQLite
6. **Worker** каждые 5 минут проверяет файл
7. При появлении новой строки → **уведомление в Telegram**

## Как подготовить Яндекс Диск

### 1. Создай папку

1. Открой [disk.yandex.ru](https://disk.yandex.ru)
2. Нажми **Создать** → **Папку**
3. Назови её, например, `SheetsNotifier`

### 2. Загрузи XLSX-файл

1. Открой Excel (или LibreOffice)
2. Создай таблицу с данными:
   ```
   Имя | Телефон | Комментарий
   Иван | 79001234567 | Первый
   ```
3. Сохрани как **XLSX** (формат Excel 2007+)
4. **Перетащи** файл в созданную папку на Яндекс Диске

⚠️ **Важно:** файл должен быть в формате `.xlsx`. CSV и XLS (старый формат) **не поддерживаются**.

### 3. Сделай папку публичной

1. **Правой кнопкой** по папке → **Поделиться**
2. Включи **Доступ по ссылке**
3. **Скопируй ссылку** — она будет вида:
   ```
   https://disk.yandex.ru/d/xxxxx
   ```

### 4. Добавь в бота

1. Нажми **➕ Добавить таблицу**
2. Отправь **ссылку на папку**
3. Укажи **имя файла** (например, `Заявки.xlsx`)
4. Укажи **название** (например, «Заявки»)
5. Укажи **номер последней строки** (1, если хочешь получать все новые)

## ⚠️ Важно: обновление файла

Бот читает **файл XLSX с Яндекс Диска**, а не онлайн-таблицу в Яндекс Документах. Это значит:

- Если ты **редактируешь онлайн-таблицу**, файл на Диске **не обновляется автоматически**
- Чтобы бот увидел изменения, нужно **перезалить XLSX**:
  1. Открой онлайн-таблицу
  2. **Файл** → **Скачать как** → **XLSX**
  3. **Перетащи** новый файл на Яндекс Диск (замени старый)
  4. Бот увидит изменения при следующей проверке

**Альтернатива:** работай **только с XLSX в Excel** — скачивай, правь, загружай обратно. Тогда всё синхронизировано.

## Как это работает под капотом

### Yandex Disk API

Бот использует метод:
```
GET https://cloud-api.yandex.net/v1/disk/public/resources/download
    ?public_key=<ссылка_на_папку>
    &path=/имя_файла.xlsx
```

Это возвращает **прямую ссылку** на скачивание файла, которую бот использует для получения XLSX.

### pandas вместо openpyxl

XLSX-файлы, созданные в Яндекс Документах, имеют **нестандартную структуру**. `openpyxl` видит только **1 строку** (пустую), а `pandas` **читает все данные корректно**.

### Worker

Worker — это **фоновая задача** в `main.py`, которая:
- Запускается через 30 секунд после старта бота
- Работает **каждые 5 минут**
- Проверяет все активные отслеживания
- Отправляет уведомления по новым строкам
